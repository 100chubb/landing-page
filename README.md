# Landing Page
For this project I am creating a simple landing page to bring together what I have learned so far with HTML and CSS from TOP (The Odin Project).

For styling, colours and fonts I decided to simply replicate the assignment design brief.

I wanted the content to be humorous and a bit tongue-in-cheek, plus to sync together nicely. I used the CERN Large Hadron Collider homepage for some of my inspiration.

Implementing the CSS styling was surprisingly challenging, yet nicely rewarding once each section was finished. Kevin Powell's videos on YouTube were immensely helpful. Thanks, Kevin!

During the project I have extended my knowledge of Git, becoming more familiar with `git add` and `git commit`, and discovering `git rm`, `git mv` and using a file called .gitignore.

I may return to this project in the future and fine tune how the CSS controls the Roboto font.
